
# Web Refresher – Student Portfolio

## Project Description

This project is a responsive student portfolio website created using HTML5, CSS3 and JavaScript. It includes information about me, my education, skills and web development projects.

## Reflection

Creating this portfolio helped me review the basic skills I learned in Web Development I. I found writing the HTML structure and adding personal information relatively straightforward. I also enjoyed choosing the orange colour scheme and organising the content using CSS Grid and Flexbox.

The most challenging part was understanding how responsive design works on different screen sizes. Testing the website using Chrome Developer Tools helped me understand how media queries change the layout.

I also practised JavaScript by adding a Dark Mode button that changes the appearance of the page.

During Web Development II, I would like to improve my JavaScript skills and become more confident in creating responsive websites independently.

## AI Assistance

I used ChatGPT as a learning aid for guidance on HTML, CSS and JavaScript, as well as troubleshooting and reviewing my work. I tested the website using Visual Studio Code and Chrome Developer Tools.
